Built on market research. Titles and keyword order now follow Adobe's official contributor guidance: a plain, accurate, descriptive title focused on the main subject — ideally under 70 characters, no brand names, no keyword stuffing, no generic marketing tails. Each image gets a different title pattern chosen from its own subject, colours, mood and composition, and colour or “copy space” wording is only used when the pixel analysis actually finds it. Keyword order is the biggest ranking factor: the first 10 keywords are the subject and the title's own words, then action and setting, then concepts, then use-cases the composition supports, with colours and technical traits last. Object and background images also pick up “no people / nobody” terms, which Adobe buyers filter on. Tip: a descriptive filename (e.g. wooden-gavel-court.jpg) or the Custom Prompt setting gives the sharpest image matching.

Free metadata generator for Adobe Stock, Shutterstock and more

Buyers find stock photos through search, so the title, keywords and description attached to each file matter as much as the image itself. This guide explains what to write — the generator above does the drafting for you.

Write titles buyers actually search

Lead with the main subject, then add the setting, style or use case — for example, what is in the image, where it is, and what a designer might use it for. Avoid vague titles, keyword stuffing and brand names. A clear, descriptive filename before you upload also helps, because the subject in the filename is woven into the draft title and keywords.

Choose relevant keywords, not the maximum

Most marketplaces allow up to 49 keywords, but relevance beats volume. Cover the subject, colours, mood, composition, orientation and likely uses, and remove anything a buyer would not type into search. Use the keyword slider and the Single Word Keywords, Transparent Background and Silhouette settings when a platform or file type calls for them.

Use the CSV workflow for batches

For a batch, generate the metadata, review and edit each card, then export one CSV with Filename, Title, Keywords, Description and Category. Keep the CSV filenames matched to the files you upload — or switch on EPS mode in Generated Data when your deliverables are .eps files — and keep a copy of the exported CSV with the batch for later uploads to other platforms.

Check each platform before you submit

Limits and rules differ: Adobe Stock, Shutterstock, Vecteezy, Depositphotos, 123RF and Magnific each have their own keyword limits, categories and content policies. Pick the platform preset before generating, then do a final check against that marketplace's current contributor guidelines before submitting.

Frequently asked

Quick answers for stock contributors.

How many keywords should I use?

Adobe Stock allows up to 49. In practice 30–40 highly relevant keywords outperform 49 generic ones. Use the slider above to set your target per batch.

Does a descriptive filename help?

Yes. If your file is named golden-retriever-puppy-park.jpg, that subject is woven into the title and keywords. Generic camera names like IMG_2041 fall back to colour, light and composition analysis.

What CSV format is exported?

Filename, Title, Keywords, Description, Category — comma-separated keywords inside one cell, exactly how most contributor upload tools import them.

Can I edit the generated metadata?

Always. Every field on every card is editable, and each card has its own copy buttons and a regenerate button if you want a fresh take.

Why does each image get a different title style?

Top-selling stock assets don't share one title template — some put the subject in its setting, some lead with an action, some with colour and mood, and some name the copy space a buyer can use. Auto mode chooses the pattern deterministically from each image's own subject words, dominant colours, brightness, tone and composition, keeps titles plain and descriptive (ideally under 70 characters, per Adobe's guidance), and shows the chosen pattern on the card. Each card's Generate button cycles that image to a different pattern than the one currently shown.
